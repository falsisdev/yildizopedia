# Endüstriyel Tasarım

Yıldız Teknik Üniversitesi **Mimarlık Fakültesi** bünyesinde yer alan Endüstriyel Tasarım, Beşiktaş (Yıldız) Yerleşkesi'nde modern araştırma altyapısı, stüdyoları, laboratuvarları ve yetkin akademik kadrosuyla eğitim ve bilimsel faaliyetlerini sürdürmektedir.

## 🏛️ Yönetim
- **Program Koordinatörlüğü:** Mimarlık Fakültesi Endüstriyel Tasarım Bölüm Koordinatörlüğü
- **Sekreterlik:** Yıldız Yerleşkesi Tasarım Bölümleri İdari Ofisi

## 🌐 Resmî Bağlantılar
- **Web Sitesi:** [http://www.mmr.yildiz.edu.tr/](http://www.mmr.yildiz.edu.tr/)
- **Yerleşke:** Beşiktaş (Yıldız) Kampüsü
