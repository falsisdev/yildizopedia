# Mimarlık

Yıldız Teknik Üniversitesi **Mimarlık Fakültesi** bünyesinde yer alan Mimarlık, Beşiktaş (Yıldız) Yerleşkesi'nde modern araştırma altyapısı, stüdyoları, laboratuvarları ve yetkin akademik kadrosuyla eğitim ve bilimsel faaliyetlerini sürdürmektedir.
